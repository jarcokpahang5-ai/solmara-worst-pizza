# The Worst Pizza Topping

A make.fun bounty entry: one funny line naming the worst pizza topping, with a one-line case against it.

**The line:** Pineapple: a fruit salad that lost a bet and landed on my pizza — sweet, soggy, and legally not a topping.

`main.py` (pure Python standard library) writes the line to `/output/entry.txt` and prints exactly that line to stdout.
